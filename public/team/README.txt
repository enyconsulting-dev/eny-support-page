Drop team headshots here.

Example:
  /public/team/member-1.jpg
  /public/team/member-2.jpg
  /public/team/member-3.jpg
  /public/team/member-4.jpg

Then make sure each `image` path in /data/team.ts matches the file name.
Square, face-centred images (600x600+) look best. JPG, PNG or WEBP all work.
If a file is missing, the card shows the person's initials instead.
